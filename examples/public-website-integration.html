Notas de Implementación

  • API URL: Cambia http://localhost:3005 a tu URL de producción
  • Validación: Este ejemplo incluye validación básica HTML5. Considera agregar validación adicional del lado del cliente.
  • CORS: Asegúrate de que tu servidor wapp permita requests desde tu dominio público
  • Analytics: El código captura parámetros UTM y referrer para tracking de marketing
  • Seguridad: En producción, considera implementar reCAPTCHA para prevenir spam
  • UX: Podrías agregar un loading spinner durante el envío del formulario

Ejemplo de Uso Programático (JavaScript)

// Crear una oportunidad desde JavaScript
async function createOpportunity(propertyId, contactInfo, type) {
    const response = await fetch('http://localhost:3005/opportunities', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
            channel: 'public_website',
            property_id: propertyId,
            email: contactInfo.email,
            phone: contactInfo.phone,
            mobile: contactInfo.mobile,
            contact_name: contactInfo.name,
            opportunity_type: type, // 'sale' o 'rental'
            messages: [contactInfo.message || 'Cliente interesado'],
            metadata: {
                utm_source: 'google',
                utm_campaign: 'summer_2024'
            }
        })
    });
    
    return await response.json();
}

// Uso
createOpportunity(123, {
    name: 'Juan Pérez',
    email: 'juan@example.com',
    mobile: '+54 9 11 1234-5678',
    message: 'Me interesa esta propiedad'
}, 'sale');
